FoldyDockApp.swift › struct FoldyDockApp Swift 5.9 
import SwiftUI

@main
struct FoldyDockApp: App {
    @NSApplicationDelegateAdaptor(AppDelegate.self) var appDelegate

    var body: some Scene {
        WindowGroup {
            DockView()
                .background(.ultraThinMaterial)
                .clipShape(RoundedRectangle(cornerRadius: 24))
                .shadow(color: .black.opacity(0.4), radius: 20)
        }
        .windowStyle(.hiddenTitleBar)
    }
}

# FoldyDock 🚀
A sleek floating dock for macOS with iOS-style folders.

## Key Highlights
- Native Swift 5.9 & SwiftUI architecture
- Interactive Folders directly docked
- Middle-click to kill unresponsive apps
- Multi-Window activity tracking dots

Speed at your fingertips.

Designed from the ground up to respect Apple's human interface guidelines with snappy physical feedback.

Left Click
Launch & Focus
Launches app or brings it to the front with an authentic spring bounce animation.
Middle Click
Instant Quit
Terminates the clicked application instantly with a quick fade-and-shrink dismissal.
Drag & Drop
Group into Folder
Drop an application icon onto another to instantly group them into a dynamic folder.
